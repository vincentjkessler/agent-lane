# Security Policy

Agent Lane executes software tasks and interacts with local project state, so security reports are treated as high priority.

Please do not publish a working exploit in a public issue. Report vulnerabilities privately to the project maintainer with:

- affected version/commit
- operating system and setup
- reproduction steps
- expected vs. observed behavior
- whether live project state, credentials, filesystem boundaries, or execution authority are affected

The alpha should be treated as pre-production software. Keep backups and use isolated test projects until a release explicitly states otherwise.
